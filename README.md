## 📖 Description

Plateforme web complète pour la gestion d'une communauté d'église avec fonctionnalités modernes :
- 💬 **Messagerie instantanée** avec WebSocket
- 📅 **Gestion d'événements** avec inscriptions
- 🎧 **Enseignements** (audio, vidéo, PDF)
- ✍️ **Blog** avec commentaires
- 📸 **Galerie** photos et vidéos
- 💰 **Dons** Mobile Money (M-Pesa, Airtel, Orange)
- 👥 **Gestion des membres** (staff, régulier, invité)
- 📱 **Design responsive** (mobile, tablette, desktop)
